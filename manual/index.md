# ZIO — projekt semestralny

W ramach pracowni specjalistycznej realizujemy **jeden wspólny projekt**: nowy system wspierający obsługę prac/projektów i wybranych procesów Działu Nauki PB.

Nie jest to sześć niezależnych projektów. Obie grupy PS pracują nad jednym produktem i jednym backlogiem.

## Najważniejsze zasady

1. Każde zadanie ma jednego właściciela.
2. Jedna osoba ma maksymalnie jedno główne zadanie `In progress`.
3. Kod trafia do `main` tylko przez Pull Request.
4. Każdy wykonuje również review lub test cudzej pracy.
5. Zadanie jest zakończone dopiero po spełnieniu Definition of Done.
6. AI jest dozwolone, ale autor odpowiada za rezultat i musi go rozumieć.
7. Źródłem prawdy dla pracy projektowej są GitHub Issues, Pull Requests i GitHub Project.

Przejdź kolejno przez strony instrukcji przed rozpoczęciem pierwszego zadania.
