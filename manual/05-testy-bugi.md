# Testy i zgłaszanie błędów

## Testowanie jest częścią zadania

Funkcjonalność bez adekwatnej weryfikacji nie jest ukończona.

W zależności od zmiany wykorzystujemy m.in.:

- testy jednostkowe,
- testy integracyjne,
- testy uprawnień,
- testy regresji,
- testy end-to-end dla krytycznych przepływów,
- testy eksploracyjne.

## Znalazłeś błąd?

Utwórz Issue typu **Bug report**. Podaj:

1. kroki do odtworzenia,
2. wynik oczekiwany,
3. wynik rzeczywisty,
4. środowisko,
5. log/screenshot, jeśli pomaga.

Nie poprawiaj dużego błędu „przy okazji” innego PR bez Issue — utrudnia to śledzenie odpowiedzialności i regresji.
