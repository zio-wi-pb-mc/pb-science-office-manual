# Ankieta startowa

Onboarding ma dwa elementy.

## 1. Profil techniczny — GitHub

Utwórz Issue typu **Student profile**. Podaj:

- imię i nazwisko,
- ranking preferowanych ról,
- samoocenę technologii,
- obszary, w których chcesz pracować,
- czy chcesz pełnić rolę tymczasowego leada.

Profil jest widoczny dla uczestników repozytorium — nie wpisuj tam prywatnych informacji.

## 2. Preferencje dotyczące składu poda — prywatnie

Informacja o 1–2 osobach, z którymi szczególnie chciałbyś pracować, jest zbierana **w osobnym prywatnym formularzu** wskazanym przez prowadzącego.

Nie umieszczamy tej informacji w GitHub Issue, ponieważ Issues w repozytorium są widoczne dla pozostałych uczestników projektu.
